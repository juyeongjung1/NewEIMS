# EIMS 追加機能・総合診断

`追加機能総合テストを実行.bat` をダブルクリックすると、進行状況を表示する診断画面がブラウザーで開きます。

追加機能は相互に依存するため、ログイン／ログアウト、共通レイアウト、権限表示、詳細画面、退職者管理を分割せず、一連の利用シナリオとして47項目を確認します。

- Spring Bootは空いているランダムポートで起動します。
- 初回のみPlaywrightとChromiumを準備します。
- 問題が見つかった項目には、その時点の画面と確認候補を表示します。
- 技術的な詳細には、取得できた場合だけSpring Bootログの`Caused by:`行を表示します。
- 診断中に登録した「診断追加」社員は、終了時に削除します。
- URL直接入力に対するサーバー側の権限制限は、設計書上の発展オプションなので必須診断に含めません。

診断結果と実際の動作に差異がある場合は、講師へ確認してください。
