# 03 退職者管理 設計書 初版

## 1. 機能概要

社員削除を物理削除ではなく論理削除に変更する。
退職者は通常の検索結果や在籍者一覧には表示せず、退職者一覧で確認できるようにする。
退職者一覧では、復元と完全削除を行えるようにする。

## 2. 実装範囲

- 社員情報に退職者フラグを追加する
- 削除処理を論理削除に変更する
- 通常検索では退職者を除外する
- 退職者一覧を表示する
- 退職者を在籍者へ復元する
- 退職者を完全削除する

## 3. 前提条件・依存関係

この機能は単独で実装可能である。

ただし、管理者だけが退職者管理を行えるようにする場合は、ログイン／権限機能が必要である。

| 関連する追加機能 | 関係 |
| --- | --- |
| ログイン／ログアウト | 退職済み社員をログイン不可にする場合に利用する |
| 権限による画面制御 | 退職者一覧、復元、完全削除を管理者のみ操作可能にする |
| デザイン改良 | 退職者一覧に共通レイアウトを適用する |
| 詳細画面及び画面遷移改善 | 詳細画面の削除ボタンを退職処理として扱う |

## 4. 画面仕様

### 退職者一覧画面

表示項目は次の通りとする。

| 項目 | 内容 |
| --- | --- |
| 社員番号 | 退職者の社員番号 |
| 氏名 | 姓名、必要に応じてフリガナ |
| 部署 | 所属部署 |
| 復元ボタン | `deleteFlg` を 0 に戻す |
| 完全削除ボタン | DBから物理削除する |

復元と完全削除は、確認画面を設けず、ボタン押下で即時反映してよい。

## 5. 処理仕様

### 論理削除

1. 削除対象の社員番号を受け取る。
2. 対象社員を取得する。
3. 対象社員の `deleteFlg` を `1` に更新する。
4. 削除完了画面を表示する。

### 通常検索

1. 社員番号、氏名、部署で検索する。
2. 通常検索では `deleteFlg = 0` の社員だけを対象にする。
3. 退職者は通常検索結果に表示しない。

### 退職者一覧

1. `deleteFlg = 1` の社員を取得する。
2. 退職者一覧画面に表示する。

### 復元

1. 復元対象の社員番号を受け取る。
2. 対象社員の `deleteFlg` を `0` に更新する。
3. 退職者一覧へ戻る。

### 完全削除

1. 完全削除対象の社員番号を受け取る。
2. 対象社員をDBから物理削除する。
3. 退職者一覧へ戻る。

## 6. データ仕様

社員情報に次の項目を追加する。

| 項目 | 内容 |
| --- | --- |
| `deleteFlg` | 0: 在籍、1: 退職 |

初期値は `0` とする。

## 7. 他機能と結合する場合の追加対応

| 結合する機能 | 追加対応 |
| --- | --- |
| ログイン／ログアウト | `deleteFlg = 1` の社員はログイン不可にする |
| 権限による画面制御 | 退職者一覧、復元、完全削除を管理者だけに表示・実行させる |
| デザイン改良 | 退職者一覧に共通レイアウトを適用する |
| 詳細画面及び画面遷移改善 | 詳細画面の削除ボタンから論理削除へ遷移する |

## 8. 完了条件

- 社員削除時にレコードが消えず、`deleteFlg` が `1` になる
- 通常検索に退職者が表示されない
- 退職者一覧に退職者のみ表示される
- 復元すると通常検索に再表示される
- 完全削除するとDBから削除される

## 9. テスト観点

| 観点 | 確認内容 |
| --- | --- |
| 論理削除 | 削除後に `deleteFlg` が `1` になる |
| 通常検索 | 退職者が表示されない |
| 退職者一覧 | 退職者のみ表示される |
| 復元 | `deleteFlg` が `0` に戻る |
| 完全削除 | レコードが物理削除される |
| 結合 | 管理者だけが退職者管理を操作できる |
