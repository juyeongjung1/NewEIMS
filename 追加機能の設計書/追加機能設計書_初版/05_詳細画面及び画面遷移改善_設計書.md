# 05 詳細画面及び画面遷移改善 設計書 初版

## 1. 機能概要

一覧や検索結果から社員詳細へ遷移しやすくする。
ログイン中社員の氏名をクリックすると、自分の詳細画面へ遷移できるようにする。
詳細画面では、社員情報を見やすく表示し、権限に応じて変更・削除ボタンを出し分ける。

## 2. 実装範囲

- 検索結果や一覧の氏名を詳細画面へのリンクにする
- 社員詳細画面を表示する
- ヘッダーのログイン社員名を本人詳細へのリンクにする
- 詳細画面に顔写真と属性情報を表示する
- 変更ボタン、削除ボタンを条件に応じて表示する
- ログイン画面から登録画面へ遷移できるリンクを配置する

## 3. 前提条件・依存関係

この機能は一部だけなら単独実装可能である。

検索結果や一覧から詳細画面へ遷移する機能は、ログインなしでも実装できる。
ただし、ログイン社員名リンクや権限によるボタン制御は、他の追加機能が必要である。

| 関連する追加機能 | 関係 |
| --- | --- |
| ログイン／ログアウト | ヘッダーのログイン社員名リンクに必要 |
| 権限による画面制御 | 変更・削除ボタンの表示制御に必要 |
| デザイン改良 | 詳細画面のレイアウトや顔写真表示に関係する |
| 退職者管理 | 削除ボタンを論理削除として扱う場合に必要 |

## 4. 画面仕様

### 検索結果・一覧画面

氏名をクリックできるリンクにする。
リンク押下時、対象社員の詳細画面へ遷移する。

### ヘッダー

ログイン機能を実装している場合、ヘッダーのログイン社員名をリンクにする。
リンク押下時、ログイン中社員本人の詳細画面へ遷移する。

### 社員詳細画面

表示項目は次の通りとする。

| 項目 | 内容 |
| --- | --- |
| 顔写真 | 社員番号に対応する画像 |
| 社員番号 | 対象社員の社員番号 |
| 氏名 | 姓名 |
| フリガナ | 姓名のカナ |
| 性別 | 男性／女性 |
| 部署 | 所属部署 |
| 権限 | 管理者／一般 |
| 退職状態 | 在籍／退職 |

## 5. 処理仕様

### 氏名リンク

1. 検索結果または一覧に社員を表示する。
2. 氏名部分に詳細画面へのリンクを設定する。
3. リンク押下時、社員番号を指定して詳細画面を表示する。

### ログイン社員名リンク

1. セッションからログイン中社員情報を取得する。
2. ヘッダーにログイン中社員名を表示する。
3. 社員名を本人詳細画面へのリンクにする。

### 詳細画面の操作ボタン

| 条件 | 変更ボタン | 削除ボタン |
| --- | --- | --- |
| 管理者 | 表示 | 表示 |
| 一般ユーザー本人 | 表示 | 非表示 |
| 一般ユーザー他人 | 非表示 | 非表示 |

削除ボタンは、退職者管理を実装している場合、物理削除ではなく論理削除へつなげる。

## 6. データ仕様

この機能単独では、新しいDB項目は必須ではない。

ただし、権限表示を行う場合は `role` を参照する。
退職状態を表示する場合は `deleteFlg` を参照する。

## 7. 他機能と結合する場合の追加対応

| 結合する機能 | 追加対応 |
| --- | --- |
| ログイン／ログアウト | ヘッダーのログイン社員名を本人詳細へのリンクにする |
| 権限による画面制御 | 変更・削除ボタンを管理者／本人条件で表示制御する |
| 退職者管理 | 削除ボタンから論理削除処理へ遷移する |
| デザイン改良 | 詳細画面に顔写真と表形式レイアウトを適用する |

## 8. 完了条件

- 検索結果や一覧の氏名から詳細画面へ遷移できる
- 詳細画面に社員情報が表示される
- ログイン中社員名から本人詳細へ遷移できる
- 権限に応じて変更・削除ボタンが表示制御される
- ログイン画面から登録画面へ遷移できる

## 9. テスト観点

| 観点 | 確認内容 |
| --- | --- |
| 氏名リンク | 一覧や検索結果から正しい詳細画面へ遷移する |
| 本人リンク | ヘッダーのログイン社員名から本人詳細へ遷移する |
| 詳細表示 | 顔写真、氏名、部署、権限、退職状態が表示される |
| 権限制御 | 管理者、本人、他人でボタン表示が変わる |
| 結合 | 削除ボタンが退職者管理の論理削除につながる |
