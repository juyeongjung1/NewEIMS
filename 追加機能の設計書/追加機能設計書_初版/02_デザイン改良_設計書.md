# 02 デザイン改良 設計書 初版

## 1. 機能概要

画面全体の見た目と使いやすさを改善する。
共通レイアウトを導入し、ヘッダー、サイドバー、メイン領域の構成をそろえる。
検索結果や一覧画面では、社員情報を見やすく表示する。

## 2. 実装範囲

- 共通レイアウトを作成する
- 各画面に共通レイアウトを適用する
- Bootstrap を使って画面の余白、表、ボタンを整える
- 検索結果や一覧画面をレスポンシブ対応にする
- 社員番号に対応する顔写真を表示する

## 3. 前提条件・依存関係

この機能は単独で実装可能である。

ただし、他の追加機能と結合する場合は、共通レイアウト内に表示制御を追加する。

| 関連する追加機能 | 関係 |
| --- | --- |
| ログイン／ログアウト | ヘッダーにログイン状態を表示する |
| 権限による画面制御 | サイドバーの管理者用メニューを表示制御する |
| 退職者管理 | 退職者管理メニューを追加する |
| 詳細画面及び画面遷移改善 | ヘッダーの社員名リンクや詳細画面の見た目を整える |

## 4. 画面仕様

### 共通レイアウト

| 領域 | 内容 |
| --- | --- |
| ヘッダー | システム名、ログイン状態表示 |
| サイドバー | トップ、社員検索、社員登録などのメニュー |
| メイン領域 | 各画面の内容を表示する |

ログイン機能を実装していない場合、ヘッダーのログイン状態表示は省略してよい。

### 検索結果・一覧画面

検索結果や社員一覧は、表形式で表示する。

表示項目の例は次の通りとする。

- 顔写真
- 社員番号
- 氏名
- フリガナ
- 部署
- 操作ボタン

操作ボタンは、権限管理を実装している場合のみ表示制御する。

## 5. 処理仕様

### 共通レイアウト適用

1. 共通レイアウトを作成する。
2. 各画面の本文部分を共通レイアウトに差し込む。
3. 画面ごとの差分は、メイン領域に記述する。

### 顔写真表示

1. 社員番号に対応する画像ファイルを参照する。
2. 画像が表示されるように、固定サイズを指定する。
3. 画像の代替テキストには社員名を設定する。

## 6. データ仕様

この機能単独では、新しいDB項目は不要である。

顔写真はDBではなく、静的ファイルとして管理する。
画像ファイル名は、社員番号に対応させる。

## 7. 他機能と結合する場合の追加対応

| 結合する機能 | 追加対応 |
| --- | --- |
| ログイン／ログアウト | ヘッダーに「ようこそ、氏名さん」とログアウトボタンを表示する |
| 権限による画面制御 | 管理者のみ、全社員一覧や退職者管理メニューを表示する |
| 退職者管理 | 退職者一覧画面にも共通レイアウトを適用する |
| 詳細画面及び画面遷移改善 | 詳細画面に顔写真と属性表を表示する |

## 8. 完了条件

- 共通レイアウトが適用されている
- 主要画面の見た目が統一されている
- 検索結果や一覧画面が見やすく表示される
- 顔写真が社員番号に対応して表示される
- 画面幅が変わっても表示が大きく崩れない

## 9. テスト観点

| 観点 | 確認内容 |
| --- | --- |
| レイアウト | 各画面でヘッダー、サイドバー、メイン領域が表示される |
| 表示 | 検索結果や一覧が表形式で見やすく表示される |
| 画像 | 社員番号に対応した顔写真が表示される |
| レスポンシブ | 画面幅を変えても大きく崩れない |
| 結合 | ログイン状態や権限に応じたメニュー表示ができる |
