# EIMS 共通機能・検索機能診断

このフォルダーには、共通機能のうち検索機能をブラウザーから確認するPlaywrightテストが入っています。

通常は、このフォルダー内のコマンドを直接操作する必要はありません。プロジェクト直下の
`検索機能テストを実行.bat` をダブルクリックしてください。

テストが終わると、初心者向けの結果報告書がブラウザーで自動的に開きます。

## 判定の意味

- **一般仕様達成**: 簡易実装の内容に加えて、一般仕様の項目もすべて動作しています。
- **簡易実装達成**: 難易度を抑えた検索機能として必要な項目が動作しています。
- **要確認**: 基本的な検索機能に問題があります。
- **参考確認**: 設計書の必須範囲外に近い堅牢性確認です。総合判定には影響しません。

## 前提

- MySQLが起動していること
- `DBSET/EIMS_DBSET` の初期データ20件が登録されていること
- Node.jsとJava 17がインストールされていること

初回のみPlaywrightとChromiumのダウンロードが行われるため、インターネット接続が必要です。
