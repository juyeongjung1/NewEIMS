# EIMS 共通機能・実装診断

このフォルダーには、共通機能の検索・登録・更新・削除をブラウザーから確認するPlaywrightテストが入っています。

通常は、このフォルダー内のコマンドを直接操作する必要はありません。プロジェクト直下の
`共通機能テストを実行.bat` をダブルクリックしてください。

ダブルクリック後は、ブラウザーに「EIMS 実装診断アプリ」が開きます。進捗率、現在の確認内容、
完了件数、合格・要確認の件数がリアルタイムに表示されます。完了後は画面のボタンから、
初心者向けの詳しい結果報告書を開けます。

確認項目は検索29件、登録34件、更新35件、削除15件の合計113件です。登録・更新・削除の
確認では診断専用の社員だけを使用し、確認後に自動削除します。既存の社員は変更・削除しません。

EIMS本体には、Windowsがその時点で空いているポートを自動的に割り当てます。通常使う
`8080`番ポートなどで別のアプリが動いていても、競合しません。

## 判定の意味

- **一般仕様達成**: 簡易実装の内容に加えて、一般仕様の項目もすべて動作しています。
- **簡易実装達成**: 難易度を抑えた共通機能として必要な項目が動作しています。
- **要確認**: 基本的な共通機能に問題があります。
- **参考確認**: 設計書の必須範囲外に近い堅牢性確認です。総合判定には影響しません。

## 前提

- MySQLが起動していること
- `DBSET/EIMS_DBSET` の初期データ20件が登録されていること
- Node.jsとJava 17がインストールされていること

初回のみPlaywrightとChromiumのダウンロードが行われるため、インターネット接続が必要です。
